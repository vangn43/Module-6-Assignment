# Module 6 Git and GitHub Practice

## Project Description
This project is for my Module 6 Activity, I used Python to practice making changes to a program, and using Git and GitHub to save my work.

## What the Program does
- Displays the project name and version number.
- Shows the basic steps of using Git
- Explains why Git is useful for tracking code changes
- Explains the difference between git commit and git push.

## How to Run the Program

1. Open `version_control_practice.py` in VS Code.
2. Run the Python program.
3. The program will display the project information and Git explanations.

## What I learned
I learned how to use Git to track the changes to my code. I also learned how to commit changes locally and push them to GitHub.
